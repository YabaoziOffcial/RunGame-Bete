## 《牧羊人之心》美术风格分析 v0.0.1
## 用途：Dragonfall（恶龙陨落）角色立绘 / UI / 道具 的美术参考与 AI 提示词模板
## 创建时间：2026-05-15

================================================================================
一、核心美术定位
================================================================================

维度             描述
--------------------------------------------------------------
画风             日式二次元赛璐璐风格 (Cel Shading)，干净勾线 + 柔和上色
基调             萌系可爱、温暖治愈，略带奇幻冒险感
角色设计         魔物娘/兽耳娘为主，人外娘化，高度拟人 + 保留魔物特征
体型比例         正常头身比 (非Q版)，约 5-6 头身，少女体型为主
配色             柔和暖色调，低饱和但不清淡，有辨识度的属性配色体系
线条             干净利落的黑色描边，粗细均匀，类似动画原画风格

================================================================================
二、角色设计核心要素
================================================================================

【魔物娘特征融合公式】
可爱少女 + 魔物特征（兽耳/角/尾巴/翅膀/鳞片/半透明身体）= 魔物娘

【具体范例】
史莱姆娘： 半透明果冻质感身体 + 少女上半身，圆润Q弹
猫娘 MIO： 猫耳 + 猫尾 + 水手服风格服饰，活泼感
狐狸娘：   狐耳 + 多条尾巴 + 和风巫女服
妖精/精灵：半透明翅膀 + 轻盈服饰 + 自然元素装饰

【服饰风格】
- 日式幻想风（和风 + 西式混搭）
- 轻量铠甲、软甲为主（不厚重）
- 大量使用蝴蝶结、缎带、花边装饰
- 属性配色体系：风=绿、火=红、水=蓝、地=黄/棕

【面部特征】
- 大眼睛（日式动画风格）
- 小鼻子（点状或简化）
- 表情丰富活泼（笑脸、wink、困惑等）
- 腮红常用

以下分类来自牧羊人之心 BWIKI 魔物图鉴，可作为 Dragonfall 各 Tier 敌人设计参考：

绿史莱姆、蓝史莱姆、红史莱姆、黄史莱姆、黄金史莱姆、公主史莱姆

阳葵、紫阳葵、海藻杜吉芽、水藻杜吉芽
特征：花/海藻人形化，保留植物元素（花瓣、叶子）

【兽系 - T1/T2 参考】
水猫呜拉喵、山猫呜拉喵、地鸟喳喳布林
特征：小型兽类拟人，Q萌风格

【元素系 - T1/T2 参考】
风仙炭玻玻、水仙炭玻玻、风精NANO、土精NANO
特征：元素结晶/气团拟人，半透明材质

【高阶魔物 - T3/T4 参考】
雷素·鸣、真护·天茧 (龙娘)、莉安夕 (鲨鱼娘)、卡库拉拉兹巴 (青蛙娘)
特征：更接近完整人形，带华丽特效和装备

六、Dragonfall vs 牧羊人之心 风格差异对照
================================================================================

方面           牧羊人之心               Dragonfall
--------------------------------------------------------------------
视角           横版 2D                  俯视/顶视角
角色类型       魔物娘收集养成           3 位女英雄 + 大量敌人
战斗           自动普攻 + 手动技能      弹幕天堂/幸存者类
敌人风格       萌系魔物娘 (可收集)      Roguelite 怪物 (敌方)
像素化         高清 2D                  GDD: 16bit 像素 + 高清立绘

【建议策略】
立绘/UI 用牧羊人之心风格（高清赛璐璐），战斗画面用 16bit 像素，
形成 "立绘精美 + 战斗像素" 的经典日式独立游戏组合（参考《歧路旅人》思路）。
